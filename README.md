# BOARDGAME.IO Ouranomachia - the Astrologers' Game
This is a game of Ouranomachia built with the boardgame.io library.

To get started clone the repository or download a zip and unzip the code. Then change into the directory and run `npm install` to download the dependencies

To launch the web app just run `npm start`. This will serve the app on port 1234. Open [http://localhost:1234](http://localhost:1234) to view it in the browser.

    git clone https://github.com/jlanawalt/bgio-astrology-plainjs.git
    cd bgio-astrology-plainjs/
    npm install
    npm start


## Getting Started with Node boardgame.io - Plain JS

This Node project was created with [boardgame.io](https://boardgame.io/) and
setup in a simiar fashion as the Plain JS version of the tutorial:

    mkdir bgio-astrology-plainjs
    cd bgio-astrology-plainjs/
    npm init --yes
    npm install boardgame.io
    npm install --save-dev parcel

The page will reload if you make edits.

Development uses the following versions:

- node v23.4.0
- npm 10.9.2
- boardgame.io 0.50.2
- parcel 2.13.3

More details on these and other dependencies can be found in the package.json and package-lock.json files.
